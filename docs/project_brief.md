# Executive Presence Audit Lab

## Objective
Build a live content-to-lead funnel that can later support funnel analysis, segmentation, lead-quality scoring, and path analysis for a shadow implementation of a growth/data science internship narrative.

## Target Audience
- Women in finance
- Client-facing professionals in consulting, tech, and advisory roles
- Early leaders preparing for higher-visibility responsibilities

## Primary Conversion
- Qualified consultation request

## Secondary Conversion
- Newsletter signup

## v1 Scope
- Website and article pages
- Newsletter signup form
- Consultation request form
- Client-side session and acquisition capture
- Local SQLite storage for leads/signups

## Non-Goals for v1
- YouTube, podcast, Instagram, TikTok
- Full production analytics stack
- LLM-based content classification
